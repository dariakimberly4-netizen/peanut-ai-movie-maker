# Peanut AI Movie Maker

Peanut turns a complete story into an organized production board of 8-second AI-video clips.

## Workflow

1. Upload character model sheets.
2. Paste the full story.
3. Peanut creates one identity-locked prompt per clip.
4. Copy each prompt into Dreamina using daily free credits.
5. Download the generated MP4 and upload it to the matching clip.
6. Track completion and play all uploaded clips in story order.

## Features

- Mobile-first, high-contrast interface
- Character-sheet-only input with automatic identity-lock prompts
- Automatic story breakdown into up to 225 eight-second clips
- One-tap prompt copying
- Direct Dreamina generation link
- MP4 upload and completion tracking per clip
- Ordered movie playback
- Reduced-motion support

## Important

Peanut prepares, organizes, and plays generated clips. Actual AI video rendering uses an external video provider and is subject to that provider's credits and terms.

## Development

Requires Node.js 22.13 or later.

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
